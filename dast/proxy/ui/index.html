Setup

AI Engine Status

1. Configure browser proxy

Point HTTP and HTTPS proxy at:

Host: 127.0.0.1 Port: 8080

Chrome/Edge: Settings → System → Open proxy settings → Manual proxy
Firefox: Preferences → Network Settings → Manual proxy configuration

2. Install the CA certificate (once)

Download and trust the CA so your browser accepts intercepted HTTPS:

Download CA Certificate

The certificate is stored at ~/.dast-ai/ca.crt and reused on every restart — you only need to install it once.

macOS (Chrome / Edge / Safari)

sudo security add-trusted-cert -d -r trustRoot \ -k /Library/Keychains/System.keychain \ ~/Downloads/dast-ai-ca.crt

Firefox (any OS)

about:preferences#privacy → Certificates → View Certificates → Authorities → Import → dast-ai-ca.crt → check "Trust this CA to identify websites"

Windows

certutil -addstore -f Root dast-ai-ca.crt
